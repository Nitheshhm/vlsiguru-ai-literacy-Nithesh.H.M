# Mission 1 — Build the AI and ML Landscape

## Research Question

What is artificial intelligence, and where exactly does machine learning fit?

## 1. Artificial Intelligence and Machine Learning

**Artificial Intelligence (AI)** is the broad field of developing computer systems that perform tasks associated with intelligent behaviour.

**Machine Learning (ML)** is a family of methods within AI that learns patterns from data to make predictions, recognise patterns, or support decisions.

**Deep Learning (DL)** is a subset of machine learning that uses neural networks with multiple layers to learn complex patterns.

**Generative AI** refers to AI systems that generate new content, such as text, images, audio, or code.

**Large Language Models (LLMs)** are models trained on large amounts of text and other tokenised data to understand and generate language.

## 2. AI and ML Mental Map
```text
Artificial Intelligence (AI)
│
├── Rule-based systems
│   └── Follow explicitly defined rules
│
└── Machine Learning (ML)
    └── Learns patterns from data
        │
        └── Deep Learning (DL)
            └── Uses multi-layer neural networks

Generative AI
└── Generates new content

Large Language Models (LLMs)
└── Process and generate language
```
**Important distinction:** Generative AI and LLMs are not separate levels in a simple hierarchy. Many generative AI systems use deep learning, and many LLMs are deep-learning models. Not every AI system uses machine learning.

## 3. Five Important Distinctions
| Concepts | Difference |
|---|---|
| AI vs. ML | AI is the broader field; ML is an approach that learns patterns from data. |
| ML vs. DL | Deep learning is a subset of ML based on multi-layer neural networks. |
| Rule-based vs. ML-based systems | Rule-based systems follow explicitly written rules, while ML systems learn patterns from data. |
| Generative AI vs. predictive ML | Generative AI produces content; predictive ML estimates a label, value, or outcome. |
| LLM vs. AI agent | An LLM processes and generates language. An AI agent can use a model, tools, and a workflow to pursue a goal. |

## 4. Three Examples Classified with Reasons

| Example | Classification | Reason |
|---|---|---|
| A calculator using predefined arithmetic operations | Rule-based software | It follows explicitly defined operations instead of learning from examples. |
| An email spam classifier trained on labelled emails | Machine Learning | It learns patterns from examples labelled as spam or not spam. |
| An AI assistant that generates answers and uses tools to complete tasks | Generative AI and potentially an AI agent | It generates content, and tool use can support a multi-step workflow. |

## 5. What Does Machine Learning Learn?

Machine learning systems learn patterns or relationships from data. During training, an algorithm adjusts a model using the available learning signal. The trained model can then make predictions or identify patterns in new data.

For example, a model trained on historical semiconductor design data could learn relationships between design characteristics and timing outcomes. Its usefulness would depend on the quality and representativeness of the data, the chosen model, and proper evaluation.

## 6. Conclusion

AI is the broad field, and machine learning is one approach within it. Deep learning is a subset of machine learning, while Generative AI describes systems that create content. LLMs are commonly based on deep learning, and AI agents may use models and tools to perform multi-step tasks.

Understanding these distinctions helps engineers decide whether a problem is better addressed with fixed rules, a machine-learning model, or a generative AI system.
